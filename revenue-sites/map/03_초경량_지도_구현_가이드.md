# ⚡ 초경량 테마 맵 공통 엔진 및 구현 가이드

본 문서는 기존 `animap`의 강력한 지도 엔진을 재활용하여, **이미지 용량 부담 없이 0.05초 만에 열리는 초경량 맵**을 공장에서 찍어내듯 찍어낼 수 있는 아키텍처 가이드입니다.

---

## 1. 단일 규격 데이터 스키마 (Unified JSON Schema)

어떤 테마 맵이든 **아래 단일 JSON 구조**만 맞추면 기존 맵 뷰어 컴포넌트 하나로 즉시 화면에 띄울 수 있습니다.

```json
[
  {
    "id": "jeju_001",
    "title": "이도2동 재활용도움센터",
    "category": "recycle_center",
    "lat": 33.4925,
    "lng": 126.5387,
    "address": "제주특별자치도 제주시 구남동5길 12",
    "badge": "24시간 매일배출",
    "tags": ["요일무관", "RFID음식물", "폐가전무료"],
    "summary": "요일 상관없이 언제든 배출 가능하며, RFID 음식물 종량제 기기 3대 완비.",
    "tel": "064-728-1234",
    "meta": {
      "highlight": true,
      "updatedAt": "2026-11-01"
    }
  }
]
```

### 왜 이 스키마가 압도적인가?
- **이미지 URL 필드가 없음**: 고화질 사진을 서버에서 수백 장 로드하지 않으므로 데이터 트래픽 비용이 **0원**에 수렴합니다.
- **초경량 압축**: 전국 5,000개 매장 기준 파일 용량이 불과 150KB입니다. (이미지 단 1장 용량 미만)
- **모바일 로딩 속도**: 4G/5G 저속 환경에서도 지도 핀이 0.05초 만에 팍 뜹니다.

---

## 2. Next.js 단일 맵 엔진 구조 (MapViewer Architecture)

테마별로 페이지를 따로 코딩할 필요 없이, URL 파라미터나 하위 경로에서 JSON 데이터 파일만 갈아 끼우는 패턴입니다.

```
animap.co.kr/
├── app/
│   ├── [theme]/page.tsx           <-- 단일 동적 라우트
│   │   ├── jeju-clean             --> jeju.json 로드
│   │   ├── factory                --> factory.json 로드
│   │   ├── rider                  --> rider.json 로드
│   │   ├── lotto                  --> lotto.json 로드
│   │   └── night-drive            --> night_drive.json 로드
│   └── components/
│       ├── MapEngine.tsx          <-- 기존 애니맵 지도 렌더러 (Leaflet/Kakao/Naver)
│       ├── CategoryFilter.tsx     <-- 가로 스크롤 단색 라인 뱃지 필터
│       ├── PlaceBottomSheet.tsx   <-- 하단 텍스트 정보 슬라이드 시트
│       └── AdSensePlacement.tsx   <-- 구글 애드센스 고수익 배치 컴포넌트
```

## 3. 애드센스 고수익 배치 전략 (지도 서비스 전용)

지도 서비스는 유저가 화면을 드래그하느라 일반 배너 광고를 보지 않는 특성이 있습니다. 따라서 **클릭률(CTR)과 노출 지속 시간(Viewability)을 극대화하는 3대 배치 공식**을 적용해야 합니다:

1. **하단 바텀 시트 (Bottom Sheet) 앵커 광고**:
   - 모바일 화면 맨 하단에 50px~100px 슬림 앵커 배너 고정.
   - 맵을 이리저리 움직여도 항상 화면에 노출되어 광고 노출 시간(Viewability) 90% 이상 유지.
2. **장소 상세 모달 내부 배너**:
   - 핀을 클릭했을 때 올라오는 상세 정보 카드(전화번호, 운영시간, 꿀팁 텍스트) **중간에 인피드(In-feed) 광고** 삽입.
   - 정보를 읽는 순간 자연스럽게 시선이 머물러 클릭률이 가장 높음.
3. **카테고리 탭 변경 시 전면 광고 (Interstitial)**:
   - '로또 명당' 보다가 '제주 쓰레기'나 '야장 포차'로 탭을 바꿀 때 자연스럽게 1회 노출.

## 4. 공공데이터 자동 갱신 파이프라인 (무인화)

사람이 일일이 엑셀을 다운받을 필요 없이 백그라운드 스크립트로 최신화합니다:

```mermaid
flowchart LR
    A["공공데이터포털 / 지자체 API"] -->|Python 정기 Cron| B["필터링 & 텍스트 정제<br/>(scripts/fetch_data.py)"]
    B -->|단일 스키마 변환| C["public/data/[theme].json"]
    C -->|Git Commit & Push| D["Vercel 자동 배포"]
```

- 공공데이터포털(data.go.kr) 오픈 API 키 발급 (100% 무료).
- 파이썬 스크립트가 매월 1일 또는 매주 토요일에 API를 호출해 JSON 파일만 최신화하여 원격 레포에 Push.
- 대표님의 손이 전혀 가지 않는 **100% 무인 자동화 지도 플랫폼** 완성.
