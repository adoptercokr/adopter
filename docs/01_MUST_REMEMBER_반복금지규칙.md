## 2. 🚨 [배포 장애] Vercel CLI 로컬 터미널 직접 배포 절대 금지
- **금지 이유**: Windows CMD/PowerShell 환경에서 `npx vercel deploy` 또는 `vercel --prod` 명령어 실행 시 `Building...` 단계에서 프로세스가 멈추며 파일이 전송되지 않고 배포가 `UNKNOWN` 상태로 실패합니다.
- **올바른 배포 방법**: 
  - 작업 완료 후 **반드시 원격 GitHub 저장소(`main` 브랜치)로 코드를 Push**합니다.
  ```bash
  git add .
  git commit -m "feat: 업데이트 완료"
  git push origin main
  ```
  - GitHub에 코드가 들어가면 Vercel 클라우드가 10초 이내에 자동 빌드(Auto Deploy)하여 가장 안정적으로 무중단 배포됩니다.

## 3. 🚨 [용량 초과] 100MB 이상 동영상/미디어 GitHub 커밋 절대 금지
- **금지 이유**: GitHub은 단일 파일 100MB 초과 시 Push를 완전히 거부하며, 커밋 히스토리가 꼬여 복구가 매우 번거로워집니다.
- **절대 규칙**:
  - 로컬 mp4 파일(수십~수백 MB)은 웹사이트에 직접 넣지 않습니다.
  - `.gitignore`에 `*.mp4`, `*.mov`, `*.zip`을 필수 등록합니다.
  - **대안**: 100vh 비디오 배경 및 전체 투어 영상은 **유튜브 쇼츠(YouTube Shorts) 스트리밍 연동 방식**을 100% 사용합니다. (CDN 무제한 트래픽 + 로딩 0초 효과)

## 4. 🚨 [UI/UX 버그] 모든 모달창 'style="display: none;"' 필수 명시
- **버그 원인**: Tailwind의 `hidden` 클래스만 줄 경우 간혹 CSS 렌더링 타이밍 이슈나 외부 스크립트 충돌로 투명한 오버레이 레이어가 화면 전체를 덮어 **"사진이나 버튼이 클릭되지 않는 먹통 현상"**이 발생합니다.
- **해결 원칙**: 모든 팝업 모달 태그에는 반드시 인라인 스타일로 디스플레이를 꺼둡니다.
  ```html
  <!-- 올바른 작성 예시 -->
  <div id="videoTourModal" style="display: none;" class="fixed inset-0 bg-black/95 z-[85] hidden ...">
  <div id="photoModal" style="display: none;" class="fixed inset-0 bg-black/95 z-[80] hidden ...">
  ```

## 5. 🚨 [모바일 붕괴] 1단어 초슬림 헤더 & 번역 깨짐 방지 ('notranslate')
- **버그 원인**: 구글 번역 엔진이 작동할 때 긴 한국어 메뉴가 긴 영문/외국어로 바뀌면서 모바일 상단 헤더가 2줄, 3줄로 찢어지는 현상 발생.
- **해결 원칙**:
  - 상단 메뉴명은 원문부터 1단어로 초슬림화: `공간(Space)` · `가격(Price)` · `시설(Facilities)` · `안내(Guide)` · `위치(Location)`
  - 브랜드명, 카피라이트, 언어 스위처 등 고유명사는 `<span translate="no" class="notranslate">`로 감싸 번역기가 멋대로 늘리지 못하게 차단.
  - 모바일 연박 할인 뱃지 등은 `whitespace-nowrap` 필수 적용.
