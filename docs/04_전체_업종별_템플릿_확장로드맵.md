# 🗺️ 전체 업종별 템플릿 확장 로드맵 (Adopter Template Bank Roadmap)

본 문서는 **어댑터(Adopter)가 보유한 웹 프로젝트 자산을 업종별 마스터 템플릿으로 규격화하여, 향후 소상공인 웹 에이전시 및 SaaS(웹빌더)로 확장하기 위한 마스터 로드맵**입니다.

---

## 🏛️ 템플릿 뱅크 7대 핵심 라인업

```
📁 templates/
 ├── 📁 01-stay/           [완료] 감성 숙소 / 풀빌라 / 단독 펜션 (희스테이 베이스)
 ├── 📁 02-homecare/       [예정] 출장 서비스 / 홈케어 / 청소 / 인테리어 (샤방홈케어 베이스)
 ├── 📁 03-qrmenu/         [예정] 식당 / 카페 / 주점 모바일 스마트메뉴판 (QR메뉴 베이스)
 ├── 📁 04-localshop/      [예정] 농수산물 직거래 / 로컬 특산품 1인 커머스 (비바리수산/영숙이네)
 ├── 📁 05-care/           [예정] 요양원 / 시니어 주간보호 / 복지시설 (시니어사이트 베이스)
 ├── 📁 06-map/            [예정] 위치기반 핫플 / 반려동물 동반 지도 (애니맵 베이스)
 └── 📁 07-event/          [예정] 룰렛 / 추억의 뽑기판 프로모션 랜딩 (룰렛/가챠 베이스)
```

## 🚀 SaaS(노코드 웹빌더) 진화 단계

1. **현재 (1인 에이전시 반자동화)**:
   - 대표님이 정보 입수 ➔ AI가 `config.js` 작성 ➔ 3분 만에 빌드 & 배포.
2. **2단계 (파이썬 로컬 GUI 빌더)**:
   - 엑셀/구글 시트에 사장님 정보만 넣고 버튼 누르면 사이트 자동 생성.
3. **3단계 (클라우드 SaaS 플랫폼)**:
   - 사장님이 웹에서 직접 로그인 ➔ 템플릿(01~07) 선택 ➔ 사진/문구 입력 ➔ 도메인 자동 바인딩.
   - 월 정기 구독료 (월 19,900원 ~ 49,900원) 결제 모델 확립.
