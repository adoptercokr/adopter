# ⚡ 숙박업 웹사이트 3분 초고속 제작 매뉴얼 (Stay Website Fast-Track Guide)

본 문서는 의뢰가 들어왔을 때 **마스터 템플릿(`templates/01-stay/`)을 복제하여 3분 만에 신규 감성 숙소 사이트를 완결**하는 표준 실무 매뉴얼입니다.

---

## ⏱️ 전체 소요 시간: 약 3분
- **1단계**: 템플릿 폴더 복사 및 프로젝트 생성 (20초)
- **2단계**: `stay_config.js` 정보 기입 (1분)
- **3단계**: 숙소 사진 10~30장 `img/` 폴더에 넣기 (1분)
- **4단계**: GitHub 푸시 및 Vercel 자동 배포 (30초)

---

## [1단계] 템플릿 복사 및 프로젝트 생성 (PowerShell)

신규 숙소명(예: `jeju-aewolstay`)으로 폴더를 복제합니다.

```powershell
# 1. 01-Nova-Web-Studio 경로로 이동
cd "c:\nas\mj\비즈니스\유튜브-SNS-캐릭터-애니\ai사이트\AI-mj공작실\01-Nova-Web-Studio"

# 2. 마스터 템플릿을 신규 숙소 폴더명으로 복제
Copy-Item -Recurse ".\adopter\templates\01-stay" -Destination ".\jeju-aewolstay"

# 3. 신규 프로젝트 폴더로 이동
cd ".\jeju-aewolstay"
```

## [3단계] 사진 파일 배치 (`img/` 폴더)

- 클라이언트가 제공한 숙소 사진을 `img/` 폴더에 넣습니다.
- 파일명은 영문 소문자 또는 한글로 깔끔하게 정리합니다. (`pool1.jpg`, `living1.jpg` 등)
- 용량이 너무 큰 경우(1장당 10MB 이상), 1920px 이하로 일괄 리사이징 권장.

## [4단계] GitHub Push 및 Vercel 자동 배포

```powershell
# 1. 새 Git 레포지토리 초기화 및 커밋
git init
git add .
git commit -m "feat: 첫 번째 릴리즈"

# 2. GitHub 원격 저장소 연결 (GitHub 웹에서 새 레포 생성 후 URL 복사)
git branch -M main
git remote add origin https://github.com/adoptercokr/신규저장소명.git
git push -u origin main
```

- GitHub에 푸시되면 Vercel이 자동으로 감지하여 10초 만에 실시간 웹사이트가 배포됩니다.
- Vercel 대시보드에서 클라이언트의 커스텀 도메인(예: `aewolstay.co.kr`)을 연결하면 모든 작업이 완료됩니다!
