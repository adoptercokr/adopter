## 1. 프로젝트 개요 및 핵심 품질 규격

- **서비스 명칭:** ColorWorld Archive (무료 색칠공부 & 교육 도안 라이브러리)
- **도안 품질:** 전 세계 박물관, 도서관, 국립공원(NPS), 아티스트들이 기증한 **실제 정통 흑백 선화 도안**
- **인쇄 표준:** A4 300DPI급 표준 해상도 (1240 x 1754 px)
- **용량 최적화:** 1-bit 적응형 무손실 흑백 압축 (파일당 30KB ~ 110KB 고화질 경량화)
- **중복률:** **0.00% (dHash 퍼셉추얼 해시 알고리즘 기반 해밍 거리 4 이하 전량 자동 폐기)**
- **출처 및 문구 은폐:** 상단 3.5% 및 하단 5.5% 자동 정밀 크롭으로 웹사이트 URL, 저작권 문구, 시트 번호 100% 제거
- **라이선스:** CC0 퍼블릭 도메인 기반 **상업적 이용 100% 자유 (출처 표기 불필요)**
- **다국어 지원:** 한국어(ko), 영어(en), 일본어(ja), 중국어(zh) 4개국어 완전 현지화

## 3. dHash 시각적 중복 0% 및 워터마크 자동 제거 기술

```python
# 1. 상하단 워터마크 및 출처 URL 자동 크롭

crop_bottom = int(h * 0.945)
img = img.crop((0, crop_top, w, crop_bottom))

# 2. dHash (Difference Hash) 64비트 시각적 지문 계산
def calc_dhash(image, hash_size=8):
    resized = image.convert('L').resize((hash_size + 1, hash_size), Image.Resampling.LANCZOS)
    pixels = list(resized.getdata())
    difference = [pixels[r*(hash_size+1)+c] > pixels[r*(hash_size+1)+c+1] 
                  for r in range(hash_size) for c in range(hash_size)]
    # 64비트 해시 반환

# 3. 해밍 거리가 4 이하인 시각적 유사/중복 이미지는 즉시 폐기
if hamming_distance(new_dhash, existing_dhash) <= 4:
```

## 4. 프론트엔드 핵심 기능 및 인터랙션

1. **메인 화면 카드 직관화:**
   - 카드 상단 우측에 `웹 색칠 가능` 뱃지 상시 노출.
   - 카드 하단에 `[웹 색칠하기]`(원클릭 스튜디오 진입)와 `[인쇄]` 버튼 상시 2분할 배치.
2. **3레이어 캔버스 디지털 페인팅 스튜디오:**
   - `paintCanvas` (하단 채색) + `tempCanvas` (드래그 버퍼) + `lineCanvas` (최상단 multiply 선화 보존).
   - 아무리 진한 색으로 색칠해도 원본 흑백 도안 선이 절대로 가려지지 않고 선명하게 유지됨.
3. **1:1 정밀 좌표 및 브러시/지우개 범위 원형 인디케이터:**
   - 마우스 포인터 위치에 실시간 브러시 굵기와 색상/투명도가 반영된 커서 링이 떠서 적용 범위를 완벽히 안내.
4. **전체 통합 검색 & 검색 버튼:**
   - 연령/테마 상관없이 돋보기 [검색] 버튼 하나로 전체 풀 실시간 통합 검색.
5. **푸터 4대 전문 법적 모달:**
   - 제휴 및 문의, 서비스 이용약관, 개인정보처리방침(회원가입 없는 100% 익명 운영), 저작권/상업적 라이선스(상업적 출판·판매 완전 자유).
