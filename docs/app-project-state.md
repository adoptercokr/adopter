# 앱 출시 프로젝트 상태 (AI용)

최종 갱신: 2026-11-20

## 확정 사항
- 계정 유형: 사업자(조직) 계정 (구글 20명 14일 테스트 면제 목적)
- 환경: 윈도우 PC 단독. 맥 없음. iOS 빌드는 GitHub Actions macOS 러너.
- 방식: Capacitor 하이브리드. 앱은 배포된 웹 URL을 로드 (웹 push로 동기화).
- 순서: 웹 배포 완료 후 앱 변환 시작.
- 대상 후보: 컬러월드(1순위 추천), 애니맵2, 위집(낮음, 앱 전용 기능 필요).
- 비용: 구글 $25(1회) + 애플 $99(연). 첫해 약 17.5만 원.

## 현재 단계
| 단계 | 상태 |
|---|---|
| D-U-N-S 신청 | 대표님 미착수 (영문 상호·주소 대기) |
