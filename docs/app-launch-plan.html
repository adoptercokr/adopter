요약
1. 웹을 먼저 배포하고, 그 웹을 앱이 불러오는 방식(Capacitor)으로 동기화합니다.
2. 지금 할 일은 D-U-N-S 번호 신청 하나입니다. 무료이고 1~2주 걸립니다.
3. 맥은 필요 없습니다. 아이폰 빌드는 GitHub 클라우드가 처리합니다.

6. 웹 배포 전 점검표

항목이유
모바일 화면 최적화앱 화면이 곧 모바일 웹입니다.
HTTPS, 고정 도메인앱이 이 주소를 불러옵니다. 바꾸면 앱 수정이 필요합니다.
개인정보처리방침, 이용약관 URL양대 스토어 필수 제출 항목입니다.
로그인이 있으면 테스트 계정애플 심사관용입니다.
오류 페이지 없음심사 중 오류가 보이면 반려됩니다.

8. D-U-N-S 번호 신청 안내

항목내용
정의전 세계 기업에 부여하는 9자리 사업자 식별 번호 (Dun & Bradstreet)
비용무료. 유료 대행은 결제하지 마세요.
기간보통 1~2주, 길면 약 1개월
준비물사업자등록증, 영문 상호명, 영문 주소, 대표자명, 대표 전화, 사업자 이메일
순서1) 애플 D-U-N-S 조회 페이지에서 상호 검색 → 2) 없으면 신청 → 3) 이메일 확인 응답 → 4) 번호를 애플·구글 가입에 입력
주의영문 상호·주소는 사업자등록증과 정확히 일치해야 합니다. 이후 가입에서도 같은 표기를 사용합니다.
