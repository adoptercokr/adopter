# 🤖 AI 최소 토큰 프롬프트 가이드 (Stay Config Extraction Prompt)

본 문서는 **숙박업체의 네이버 플레이스 링크, 인스타그램, 에어비앤비 설명문, 메모 텍스트를 바탕으로 AI가 단 500~800 토큰만 소모하여 `stay_config.js`를 즉시 완성**할 수 있도록 설계된 전용 프롬프트입니다.

---

## 📌 왜 전체 HTML을 생성하지 않는가?
- 전체 `index.html`을 생성할 경우: **약 30,000 ~ 60,000 토큰 소모** + 생성 지연 3분 + 자바스크립트 버그 발생 위험
- `stay_config.js` 데이터만 추출할 경우: **약 500 ~ 800 토큰 소모** + 생성 시간 3초 + 버그 발생률 0%

---

## 📋 AI 입력용 마스터 프롬프트 (복사하여 사용)

AI에게 아래 프롬프트와 함께 클라이언트 정보를 붙여넣으십시오.

````markdown
[숙박업체 정보 -> stay_config.js 자동 변환 요청]

너는 감성 숙소 웹사이트 전문 데이터 엔지니어이자 카피라이터야.
아래 제공된 [업체 원본 정보]를 분석하여 `templates/01-stay/stay_config.js`에 들어갈 완성된 JavaScript 객체 코드만 작성해줘.

■ 절대 준수 규칙 (MUST REMEMBER):
1. 농어촌민박업 법률상 '독채' 단어는 절대로 사용하지 마. 반드시 '단독주택', '단독 풀빌라', '프라이빗 단독 숙소'로만 표현해.
2. 메인 카피는 감성적이고 정갈한 톤앤매너로 1~2줄로 다듬어줘.
3. 3대 무료 혜택(수영장, 자쿠지, 바베큐 등 숙소의 무료 서비스)을 매력적인 카피로 정돈해.
4. 요금 정보(평일, 주말, 최소박수, 연박할인율)를 숫자로 깔끔하게 정리해.
5. 오직 `const STAY_CONFIG = { ... };` 코드 블록만 출력하고, 다른 설명이나 인사는 일체 생략해.

[업체 원본 정보]:
(여기에 네이버 플레이스 정보, 에어비앤비 링크 내용, 카카오톡 메모 등을 그대로 붙여넣으세요)
````
